# Project: ChatGPT PM MCP — Demo
_Last updated: 2026-05-04_

## What This Is
This is the included demo project for testing the ChatGPT PM MCP workflow. It is a small generic Express API starter with sample tasks and project context, used to verify the full ChatGPT → MCP → Claude Code → response loop.

## Current State
- `example-prompt.md` — sample task prompt for testing the MCP handoff
- `mcp-response.example.md` — example of what a Claude Code response looks like
- `TASKS.md` — sample backlog tasks

## Active Goal
Verifying that ChatGPT can manage project context, send scoped work to Claude Code via the MCP bridge, and read responses back correctly.

## How to Use ChatGPT PM
Type `/resume` in your ChatGPT Project to reload this context.
Type `/plan [task]` to plan and send a task to Claude Code.
Type `/send` to have ChatGPT submit the plan via MCP.
Type `/response` to read what Claude Code did.
Type `/check` to verify the MCP connection and available tools.
