# Project: Express API Demo
_Last updated: 2026-05-03_

## What This Is
A simple Express.js REST API with user authentication and basic CRUD routes. Used as a demo project for the chatgpt-pm-mcp setup.

## Current State
- Express server running on port 3000
- Routes: GET /users, POST /users, GET /users/:id, DELETE /users/:id
- Basic JWT auth middleware on protected routes
- No rate limiting yet
- Tests: none

## Active Goal
Add rate limiting to the auth endpoint and write a basic test for it.

## Key Files
- `server.js` — main Express app
- `routes/auth.js` — login/register endpoints
- `routes/users.js` — user CRUD
- `middleware/auth.js` — JWT verification
- `package.json` — dependencies
